# 🎯 Guide d'utilisation - Système de réservation de visites amélioré

## Pour les clients (utilisateurs cherchant un logement)

### 📱 Réserver une visite

1. **Accédez à l'onglet "Visites"** dans l'application
2. **Sélectionnez "Réserver"** dans le menu
3. **Suivez les étapes** :
   - 🏠 **Étape 1** : Choisissez un logement dans la liste
   - 📅 **Étape 2** : Sélectionnez la date et l'heure de votre visite
   - 📞 **Étape 3** : Ajoutez vos coordonnées et notes (optionnel)
4. **Confirmez** votre réservation

### ⚠️ Limitation importante

**Vous ne pouvez avoir qu'une seule visite active à la fois !**

Une visite est considérée comme "active" si elle est :
- 🟠 **En attente** de validation par le propriétaire
- 🟢 **Acceptée** par le propriétaire

**Que faire si vous avez déjà une visite active ?**

Si vous essayez de réserver une nouvelle visite alors que vous en avez déjà une active, vous verrez :

```
⚠️ Visite active en cours
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🏠 Appartement Vue Mer
📅 15 décembre 2025
⏰ 14:30
🟢 Acceptée

💡 Annulez ou terminez cette visite 
   pour en réserver une nouvelle
```

**Options disponibles :**
1. **Attendre** que la visite ait lieu
2. **Annuler** la visite actuelle si vous changez d'avis
3. **Marquer comme effectuée** après avoir visité le logement

### 📊 Consulter vos visites

Dans l'onglet **"Mes visites"**, vous verrez :

#### Résumé statistique
```
📊 Résumé de vos visites
3 visites au total

┌──────────┐  ┌──────────┐
│ 🕐 1     │  │ ✅ 1     │
│ En att.  │  │ Acceptées│
└──────────┘  └──────────┘
┌──────────┐  ┌──────────┐
│ 🏁 1     │  │ ❌ 0     │
│ Terminées│  │ Annulées │
└──────────┘  └──────────┘

⚠️ Vous avez une visite active
```

#### Filtres disponibles
- **Toutes** : Voir toutes vos visites
- **En attente** 🟠 : Visites en attente de validation
- **Acceptées** 🟢 : Visites confirmées par le propriétaire
- **Refusées** 🔴 : Visites refusées
- **Terminées** 🔵 : Visites complétées

### 🎬 Actions possibles sur une visite

Selon le statut de votre visite, vous pouvez :

#### Visite en attente 🟠
- ✏️ **Modifier** : Changer la date/heure ou les notes
- ❌ **Annuler** : Annuler la demande de visite
- 🗑️ **Supprimer** : Supprimer définitivement la visite

#### Visite acceptée 🟢
- ❌ **Annuler** : Annuler la visite confirmée
- ✅ **Marquer comme effectuée** : Après avoir visité le logement

#### Visite terminée 🔵
- ⭐ **Évaluer** : Laisser un avis sur le logement et le propriétaire

## Pour les propriétaires (colocataires)

### 📥 Gérer les demandes de visite

1. **Accédez à l'onglet "Visites"**
2. **Sélectionnez "Demandes"** dans le menu
3. **Consultez** les demandes reçues

### 🎯 Actions sur les demandes

Pour chaque demande, vous pouvez :

#### Demande en attente
- ✅ **Accepter** : Confirmer la visite
- ❌ **Refuser** : Décliner la demande

#### Demande acceptée
- 👁️ **Voir l'avis** : Consulter l'évaluation du client (si disponible)

### 📊 Consulter les avis reçus

Dans l'onglet **"Reviews"**, vous pouvez :
- Voir tous les avis laissés par les visiteurs
- Consulter les détails de chaque évaluation
- Suivre votre réputation

## 💡 Conseils et bonnes pratiques

### Pour les clients

1. **Planifiez à l'avance** : Réservez votre visite plusieurs jours à l'avance
2. **Soyez précis** : Ajoutez des notes pour préciser vos disponibilités
3. **Respectez vos engagements** : Si vous ne pouvez pas venir, annulez à temps
4. **Laissez un avis** : Aidez les autres utilisateurs avec votre retour d'expérience
5. **Une visite à la fois** : Concentrez-vous sur une propriété avant d'en explorer d'autres

### Pour les propriétaires

1. **Répondez rapidement** : Acceptez ou refusez les demandes dans les 24h
2. **Soyez disponible** : Assurez-vous d'être présent à l'heure convenue
3. **Préparez le logement** : Nettoyez et rangez avant la visite
4. **Soyez accueillant** : Une bonne première impression est importante
5. **Suivez vos avis** : Utilisez les retours pour améliorer votre service

## 🔔 Notifications

Vous recevrez des notifications pour :
- ✅ Visite acceptée par le propriétaire
- ❌ Visite refusée
- 📅 Rappel 24h avant la visite
- ⭐ Demande d'évaluation après la visite
- 💬 Nouveau message du propriétaire

## ❓ Questions fréquentes

### Puis-je réserver plusieurs visites en même temps ?
Non, vous ne pouvez avoir qu'une seule visite active (en attente ou acceptée) à la fois. Cela garantit que vous vous concentrez sur chaque propriété et respectez vos engagements.

### Que se passe-t-il si je ne peux plus venir à ma visite ?
Annulez votre visite dès que possible depuis l'onglet "Mes visites". Le propriétaire sera notifié et vous pourrez réserver une nouvelle visite.

### Combien de temps ai-je pour évaluer une visite ?
Vous pouvez évaluer une visite à tout moment après l'avoir marquée comme effectuée. Nous recommandons de le faire dans les 48h pour que votre avis soit le plus précis possible.

### Le propriétaire peut-il voir mon numéro de téléphone ?
Oui, si vous l'avez renseigné lors de la réservation. C'est utile pour que le propriétaire puisse vous contacter en cas de besoin.

### Puis-je modifier une visite déjà acceptée ?
Non, une fois acceptée, vous ne pouvez que l'annuler. Pour modifier les détails, annulez d'abord la visite puis créez-en une nouvelle.
