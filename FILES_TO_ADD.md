# Fichiers à ajouter au projet Xcode

Veuillez ajouter les fichiers suivants à votre projet Xcode (Clic droit sur le dossier "DarnaApp" dans Xcode -> "Add Files to DarnaApp...") :

1.  `DarnaApp/Models/RouletteConfig.swift`
2.  `DarnaApp/Services/RouletteEngine.swift`
3.  `DarnaApp/ViewModels/PubliciteDetailViewModel.swift`
4.  `DarnaApp/Views/Components/RouletteSegmentView.swift`
5.  `DarnaApp/Views/Components/RouletteView.swift`
6.  `DarnaApp/Views/Components/QRCodeConfirmationView.swift`

**Note :** Le fichier `DarnaApp/Views/Screens/PubliciteDetailView.swift` devrait déjà être dans le projet. Si ce n'est pas le cas, ajoutez-le également.

Une fois ces fichiers ajoutés, le projet devrait compiler correctement.
